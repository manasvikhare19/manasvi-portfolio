AgriScan — Crop Disease Detection Platform
Independent Build
  • Conducted user problem discovery with farmers, identifying an unmet need for early, low-cost crop disease detection; scoped and shipped an ML solution covering 57 disease classes across 14 crops at 84.6% accuracy (MobileNetV2).
  • Optimized the deployed model via TFLite conversion — a data-driven fix after usability feedback showed the initial version was too slow on basic phones.
